# PrintNSell

A full-stack MERN e-commerce platform for buying and selling 3D-printed products.

## Tech Stack

* React
* Vite
* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

## Features

* User registration and login
* Product browsing
* Product details
* Shopping cart
* Checkout
* Address management
* Order management
* Seller dashboard
* Product management
* Product reviews
* Authentication and authorization

## Project Structure

```text
PrintNSell/
├── backend/
├── public/
├── src/
├── package.json
└── README.md
```

## Getting Started

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```

Create a `backend/.env` file and add your required environment variables.
